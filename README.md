# Emotion-Recognition-Using-ConvNeXt
CSCI 4900 Final Project
Steps to Running Emotion Recognition Software

Using Google Colab, Follow these instructions:
1. Import all files present within the import.py file
2. Run the data preprocessing file <datapreprocess.py> to begin formatting the dataset
3. Load the preprocessed data using the file <load.py>
4. Run the training model and test benchmarks using <train_and_test.py>
5. Upload sample picture .jpg files to Google Colab
6. Test sample images using <emotion_recognition.py> by inserting your file name at custom_image_path = "<filename.jpg>"
